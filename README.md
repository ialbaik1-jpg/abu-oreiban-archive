# أرشيف مخيم أبو عريبان

تطبيق PWA عربي RTL يعمل محلياً باستخدام IndexedDB مع 30 سجلاً تجريبياً.

## تشغيل محلي

```bash
npm install
npm run dev
```

ثم افتح الرابط الذي يعرضه Vite. للبناء: `npm run build`، والمخرجات في `dist/`.

## النشر على Cloudflare Pages

1. ارفع هذا المجلد إلى مستودع GitHub خاص.
2. في Cloudflare > Workers & Pages > Create > Pages > Connect to Git.
3. اختر المستودع؛ Build command: `npm run build` و Output directory: `dist`.
4. انشر على HTTPS، ثم افتح الموقع واختر «تثبيت التطبيق» من المتصفح.
5. للاستخدام الفعلي، استبدل وضع الدخول التجريبي بمصادقة خادمية وربط Worker/R2/D1 وتشفير ملفات العائلات.

## ما يعمل في هذه النسخة

- الرئيسية، البحث الفوري، الخط الزمني، الألبومات، التقارير، الوضع الليلي.
- رفع ملفات فعلية وحفظها محلياً وبصمة SHA-256؛ استعادة بيانات وصفية عبر JSON.
- رسم ختم، ختم نصي، استيراد صورة ختم، ختم الصور وPDF مع الاحتفاظ بالأصل.
- شهادة PDF إنجليزية الحقول بسبب حدود الخطوط المضمنة، مع QR والبصمة.
- مقارنة صورتين قبل/بعد، سلة محلية، سجل نشاط، قسم PIN تجريبي.
- PWA وService Worker لتشغيل الواجهة دون اتصال بعد أول تحميل.

## قيود أمان ووظائف مهمة

هذا **نموذج عملي محلي** وليس خدمة إنتاجية. الدخول وكلمة المرور وPIN (1234) تجريبية وليست آمنة. لا تحفظ بيانات عائلات حساسة أو وثائق سرية قبل إضافة مصادقة خادمية وتشفير. لا توجد مزامنة Cloudflare حقيقية بعد، ولا R2/D1 متصلان، ولا صلاحيات مدير/محرر/مشاهد، ولا تشفير أختام، ولا تحقق عام من QR، ولا توقيع رقمي قانوني. النسخة الاحتياطية JSON لا تحتوي على الملفات الثنائية. تطبيق الختم يضعه في موضع افتراضي في أول صفحة PDF أو الصورة، والسحب في المعاينة ليس مرتبطاً بعد بإحداثيات التصدير. لا يوجد ختم جماعي أو معالجة متعددة الصفحات. تأكد من سعة IndexedDB على جهازك قبل تحميل ملفات كبيرة.
